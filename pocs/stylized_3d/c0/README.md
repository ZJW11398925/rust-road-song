## 启动与自动检查

使用 Godot 打开此目录的 `project.godot` 后运行工程；或在本目录执行：

```
godot --path .
godot --headless --path . --script res://spatial_smoke.gd
```

渲染采样使用非 headless 运行上述探针并追加 `-- --capture-dir=<输出目录>`。驶出后显示“实验到此结束”，车辆停在可见范围，驾驶输入结束；R、1/2 与 Esc 仍可使用。这是本轮实验边界，不是道路、剧情锁或结算系统。
