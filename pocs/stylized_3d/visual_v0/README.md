# V0 视觉语言试样

RB-V0-001 / CHG-20261013-012。这个独立工程沿首见、自由触碰、母亲协助、启动和短距驶出检验一组形、面、色、光候选。Owner采用实验范围，具体造型与参数仍可撤回；短驶出不表示母亲已经决定离家。

直接打开本目录 `project.godot`，正式入口为 `visual_v0.tscn`。WASD 步行，E 开门或触碰，F 登车或按住启动；驾驶时 W/S 前进或倒车，A/D 有限转向，松键停住。R 重置，Esc 退出。车库门保持原高度和实体碰撞，挡住人物或玛丽时仅表现自动淡化。

## 本轮候选结构

玛丽保留原外包络、下车体与碰撞。无碰撞上部从 `2.1×0.75×2.4m` 改为 `2.36×0.52×2.65m`，降低最高大形并加一块短前肩，试验低而厚的体积。三小块不齐维修钢板和一道概括接缝表达重复使用；钢板与旧漆分材质，和既有裂口/分枝组织保持形状及颜色区别。维修板与底面错开，未增加新故事道具、维修解说或异常答案。

旧漆采用偏哑光灰绿，维修钢较亮，底盘为深冷灰；暖锈色仅保留在旧损伤附近。车库冷灰蓝，母亲低饱和暖色、玩家冷色；人形的头略缩小并减少分段，袖、裤与裸手分色。肩肘手距离、伸手、接点、座位、踏步、履带和碰撞均保留占位，未做正式协作动画或人物面部。

环境光与克制方向光支撑平面阴影，没有英雄逆光或发光异常。现有底部提示条从150px收为90px，标题与帮助同排，既有短句移到左上，给腿部观察留出空间；没有扩建UI框架。
