# 叙事语言 / P2

版本：0.1；依据 OD-013..014；POC 用于检验这套语言是否有效。

## 可操作剧情

普通人物说话时原则上仍可移动、观察、靠近、有限交互。事情发生在玩家身边，不能每句话就停止游戏。字幕位置、范围和时序须保证关键消息可读且不挡观察；走开时如何保留必要信息由方案说明，不预建对话引擎。

只有重要决定、重要物件首次出现、不可逆事件允许极短演出。每次锁输入必须列原因、开始与结束、恢复方法及可跳过/重放提案。玛丽首见可极短取景，但玩家的接近、检查、发现不能被演出包办。短演出时长上限留 Owner 审查，不擅定正式数值。

## 环境叙事

过去优先由旧物、照片、修补痕迹、房间、机械、广播、人物动作、使用痕迹传达。每件重要物品要能被看见、理解并在后续获得新意义。
不让 NPC 长篇讲解父亲历史、战争背景或异常答案。场景装饰若玩家看不见、看不懂，不能算已表达故事。

POC 先挑少量家庭痕迹做足可读性。例如座椅留下未完成修补，工具位置带有家庭使用痕迹。它们是表现候选，需与美术方案一起审查。

## 对话门槛

每句台词至少服务：想得到什么、回避什么、隐瞒什么、关系变化、性格、玩家理解变化。没有功能的世界观讲解优先删。
正式台词需列说话者、当下目的、动作/触发、玩家仍可做什么、信息变化；别让角色像编剧解释设定。POC 不写超过当前片段所需的往事。

## 当前表现层的冻结边界

按 [外部审查建议](governance/sources/2026-10-10-external-reboot-review.md)，当前不细写或锁死 S00–S15 逐句正式对白。首单先记录人物想什么、各自知道/不知道什么、信息何时改变、玩家此刻做什么；具体措辞、字幕/动作分工随视觉空间验证再审。不得借这个步骤扩写全序章或提前决定母亲动作的正式资产。

## 重复与克制

道路、玛丽、信以及候选旧歌的重复必须带来意义变化，不能只刷存在感。第一异常不揭底；启动不强迫史诗配乐，不靠粒子把旧车神化。
文案进入可本地化内容，字幕/观察文本与资源路径分开。文字数量、字速、距离触发与声音暂是技术提案，不继承 Legacy 对话菜单。

## 失败检查

台词时移动后可否回到检查？字幕是否遮挡损伤？重按交互是否跳过关键发现？启动失败是否有场内可理解反馈？短演出结束是否恢复控制？这些都须在真实输入流程验证；只调用方法不足以证明。
