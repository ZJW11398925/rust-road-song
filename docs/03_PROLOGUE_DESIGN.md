# 序章《离家》规范 / P2

版本：0.2；暂定标题；依据 OD-008..013。以下是整体剧情方向，不是本轮开发清单。

## 核心体验

玩家亲自生活在一个已经快无法继续存在的家中，最终与母亲驾驶重新启动的玛丽离开。序章不是教程集合，不以战斗、装备和商店教学填充空白。

| 顺序 | 节拍 | 玩家经历与设计约束 |
|---|---|---|
| 1 | 下雨、漏水与日常生活 | 玩家在生活里感到家正在坏，不先读背景介绍 |
| 2 | 认识正在坏掉的家 | 观察/使用少量日常物件；不做搜集任务列表 |
| 3 | 最后一批熟人迁徙 | 周围人行动传达离开正在发生 |
| 4 | 母亲再次拒绝 | 留家的情感理由成立，不贬低母亲 |
| 5 | 父亲来信 | 不再等待、立即离开、带玛丽；文字保持熟悉语气 |
| 6 | 地下车库重新打开 | 主角一年未进，时间通过空间痕迹传达 |
| 7 | 玛丽第一次出现 | 首感是旧与家庭归属；允许极短演出 |
| 8 | 亲自检查 | 靠近、观察、有限交互，而非一页属性表 |
| 9 | 发现异常 | 旧损伤发生不可能变化；留下私人谜团 |
| 10 | 与母亲重新启动 | 两个人做具体事情，不把母亲变成被动乘员 |
| 11 | 第一次短距离驾驶 | 极短，理解体积与重量；不是荒野探索或战斗 |
| 12 | 最后一个夜晚 | 给家和重要物件新的意义，不集中灌输历史 |
| 13 | 环境继续恶化 | 留下变得客观不可行，不只靠台词强迫 |
| 14 | 母亲决定离开 | 她作决定；允许短演出，后果由玩家承担 |
| 15 | 驾驶离开故乡 | 玩家亲自驾驶，不以剪辑代替 |
| 16 | 进入公路显示《锈路长歌》 | 标题落在真实离开之后，收束并打开未来旅程 |

## 顺序与世界限制

表中顺序是作者希望的体验顺序，不是必须依次解锁的任务链。玩家先到驾驶位、先尝试发动、先看另一部位，原则上允许。只有真实物理限制可以硬阻止行为，例如门未开不能穿门；未看损伤不是机械故障。若启动失败，须有机械原因和可理解的场内反应，不能第一次固定失败后靠“看过”放行。

## 本轮截取

里程碑最终截取车库首见、检查、异常、启动、驶出。当前 C0 再缩为车库空间、看车、接近/绕车、空间参照位置、单次进入驾驶与低速驶出；不做家庭物件、母亲叙事、异常美术或正式对白。C0 后才审 C1，见 [当前 POC 方案](06_VISUAL_POC_PLAN.md)。不实现熟人群像、完整来信演出、最后一夜、故乡大场景或全序章标题演出。
独立 POC 进入前可提供一句中性背景：“父亲离开约一年，主角也约一年没进车库。”这是实验上下文，不是正式游戏旁白，也不提供完整情感关系。不能据此对玛丽是否成为“家”作结论；不锁定前置剧情时长。

## 未定细节

具体台词、每节时长、物件数量、驾驶结构、不可逆恶化事件和母亲动作未定。执行者只能提出与当前片段有关的有限建议，不填充后续全线剧情。
