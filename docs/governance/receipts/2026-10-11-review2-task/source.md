## 来源与主体

Owner 在本对话提供第二轮外部评审，要求“请仔细分析”。外评结论：“RB-DISC-001 作为 Discovery 交付，我建议通过外部评审；但它提出的下一阶段实验方案不能原样批准。”执行 Agent 已核实际报告和正式状态，提出落实以下七项及两条保护；Owner 随后原话：“认同”。因此本轮采用这些方向；外部评审本身不具有 Owner 权限，也不是原生 REVIEW/FINDING。

## 已采用的七项方向

1. Discovery → Greybox → Visual 三门；Garage POC 只验证空间、表现、操作，不证明完整情感关系。
2. Godot + Windows + 键盘作为当前 POC 环境，不锁定产品引擎。
3. C 为第一条风险路线；先 C0 Spatial Spike，再决定 C1 Narrative Greybox，不一次批准报告的 30h。
4. 修改 OD-015：三路线须公平审查，只有明确体验假设的路线进入可玩实施。A 保持候选；B 暂不实施，先证明独立艺术/体验主张；C 先试不等于获胜。
5. 作者希望的剧情顺序与世界物理限制分开；合理的提前发动、检查其他部位等原则上允许，剧情通过世界反应收束，禁止隐藏 Quest 状态硬锁。
6. 4/5、3/5 等比例仅是诊断参考；不以家庭痕迹数量或辨认比例作为内容 KPI，不为通过指标加强提示；记录自然行为、复述与误解。
7. C1 以人物戏可读性为核心：不用面捕/脸部特写，仅靠站位、身体动作、停顿、声音与有限镜头，检验母亲能否像一个人。

## 已采用的两条补充保护

- 强制第一次发动失败，再由 damage_seen=true 解锁，仍是隐藏任务；任何启动限制须有真实物理原因，仅观察不改变机械状态。外评的发动失败/母亲台词是示例，不是必演事件。
- C1 的局部人物戏可读性不等于完整家庭情感验证。后者需要适当前置关系；不因此扩建二三十分钟序章，也不锁定该时长。
