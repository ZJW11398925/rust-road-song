# 所有者决定 / P0

版本：0.1；生效日期：2026-10-10；来源：[本轮指令摘录](governance/sources/2026-10-10-owner-reset.md)。
本文件转录所有者本轮提供并要求落实的方向，不是 Agent 自行创作的新裁决。只有 Owner 能修改已确认方向；修订必须记录新来源、理由、影响和被替代编号。

| OD-020 | 首张执行工单只审计设计惯性并比较最小技术方案 | 不写游戏代码；提交选择建议、目录、资产、指标后等待 Owner 审查 |
| OD-021 | 每项新功能开工前必须有五项需求说明 | PLAYER NEED / NARRATIVE或GAMEPLAY CONTEXT / MINIMUM IMPLEMENTATION / WHY NOT LESS / LEGACY DEPENDENCY |
| OD-022 | 本次建库与后续开发依据 DMCP 标准及工作流 | 原话、正式对象、依据、回执、未决与交接可追溯；不伪造准入 |

## 尚未裁定 / 不得自行确认

- V-01：暗红锈蚀 / 新生金属组织是首个异常的候选表现；像腐败又像修复/生长，不等于设定真相。
- V-02：道路、玛丽、父亲的信为母题；收音机残缺旧歌是候选。旧歌若采用，标题最终须与其有真实关系。
- V-03：纯像素 2D、混合 2.5D、风格化全 3D 均未胜出；镜头参数与资产规格未定。
- V-04：主人公年龄、姓名、形象，母亲姓名，时代/地理精确背景，战争成因，父亲结局，玛丽型号、轮/履带结构、损伤位置，异常本质未定。
- V-05：引擎、平台及插件锁定须由首张工单提出有限方案；旧 Godot 4.7.1 经验不自动具有产品权威。
- V-06：试玩人数、时长预算、评分门槛和资产预算是验证方案提案，不能伪称 Owner 已批准。

## 当前冻结范围

完整个人装备、多车辆、大型零件商店、完整赏金、技能树、派系、大规模经济、复杂职业、大地图、完整战斗。旧 QuestService、WorldService、BountyDirector、存档、输入、本地化和测试框架没有自动准入权；本地化可能很快需要，但仍逐项评估。

## 冲突处理

方向冲突时先暂停依赖该冲突的实现，读来源并登记到 CURRENT；不得用低等级代码、旧 UI 标杆、旧设计文档或 DMCP 结构 READY 推翻本文件。范围、视觉胜出与未决剧情必须由 Owner 明确裁定。
