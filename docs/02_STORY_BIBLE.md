# 故事基础 / P1

版本：0.1；[Owner Decisions](00_OWNER_DECISIONS.md) OD-007..011、OD-014；方向已确认，细节未全部裁定。

## 世界与时间

持续中的平叛战争已经约一年。战争开始后，世界出现异常且不断加速的衰败；这里确认时间上的相伴，不确认战争制造异常，也不裁定叛军/政府善恶或完整历史。
当地人口不断迁徙。原来的房屋长期漏风漏雨，出现异常衰败。家不是一张可升级菜单，而是玩家亲自认识、最终无法继续居住的地方。

## 家庭

父亲是军人，战争开始后被征召。母子仍住原家，本来也应离开。母亲坚持留下，因为如果所有人离开，父亲回来也再没有家可以回。她并非单纯相信丈夫一定归来。最终离开决定必须由她作出，不能让她只是被玩家拖走的任务对象。

主角约一年没有进入地下车库。具体年龄、姓名、外貌、性格和童年事件未裁定，不擅自建立完整角色传记。

## 最后一封信

故事开始的一天，母子收到父亲从战场寄来的最后一封信。它报告战局彻底恶化，要求不要再等、立即离开，提醒不要忘记老战车玛丽，并以熟悉语气说“玛丽大展身手的时代到了。”

“最后一封”不等于已确认阵亡；不增加死亡证明、遗言、阴谋答案或完整信件文本。写正式台词前先保留这些信息功能，让文字像父亲而不是设定讲解员。

## 玛丽

她是古老、破旧、多次被父亲自行维修改装、长期属于家庭的老战车。父亲离开后停在地下车库。她不是普通初始载具，而是整个作品的重要人物级对象。

首见先让人感到旧。父亲未修好的座椅、小时候的工具、手焊痕迹、磨损与家庭装饰都是可选的家庭痕迹，不要求一次堆满。首次 POC 选择少数能够被玩家观察到并复述的细节；具体造型先审。
不赋予天选、传奇古代兵器、高科技秘密武器或直接讲话的人工智能身份。家庭对她的称呼可以拟人，不能由称呼推出其意识真相。

## 首个异常

父亲走前存在明确损伤；一年后出现不可能变化。损伤位置、以前形状和现在变化必须能让玩家理解“这不是一般维修”，无需解释异常来源。

暗红锈蚀 / 新生金属组织为候选：既像腐败又像修复，甚至像生长。不能把它直接命名为生物金属、治疗能力或解锁升级树。
第一个问题是私人的：“玛丽这一年发生了什么？”答案暂不提供。
