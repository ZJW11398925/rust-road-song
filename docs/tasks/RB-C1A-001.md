# RB-C1A-001：First Meeting

状态：VERIFYING；Owner 按 RD-009 授权，来源 [认同](../governance/sources/2026-10-11-owner-c0-close-c1a.md)。新 DEC@2/PLAN@1/TASK@1 已实际登记，prototype_execution@1 返回 READY 4 requirements/4 facts，见 binding 与本轮回执。C0 冻结；本任务不沿旧 garage.gd 增长。

## PLAYER NEED

玩家自由走近玛丽时，应能看到母亲与旧车之间一个熟悉的动作，并主动接近或触碰；若人物戏只能靠特写、漂亮资产或讲解，当前 C 路线还不成立。

## NARRATIVE / GAMEPLAY CONTEXT

C1-A 只回答“这个 3D 舞台能否承载一小段安静的人物戏”。门打开、玛丽逐渐显露、两个人进入、自由绕车、母亲一个动作/停顿、少量短文本或沉默、第一次主动触碰即结束。2–4 分钟是预计长度，不是节拍门槛或 KPI。无家庭前置，不证明爱上玛丽或完整家庭关系。

## MINIMUM IMPLEMENTATION

Godot + Windows + 键盘仅用于 POC。静态场景组织灰盒车库、门、粗车、人形占位和场景内有限镜头构图；局部阶段脚本与最小人形动作脚本，不建通用框架。母亲走到车旁、停顿、转身、把手搭到占位侧板等只是待检验候选动作，不是正式车辆设定。只允许一件自然观察的细节，不增加互动热点列表。WASD 移动，E 就近开门/触碰，R 重置，Esc 退出；不出现驾驶 Profile UI。

## WHY NOT LESS

胶囊无法表达朝向、手臂、停顿。静态图无法观察自由走动是否破坏构图/动作，也无法测试打开门时的首次显露。最低人形、一个动作和真实输入已足够；无需正式美术、完整序章、异常或驾驶。

## LEGACY DEPENDENCY

NONE；不复制 Legacy 或 C0 工程。只提炼当前已知移动/受约束镜头/输入清理经验；C0 控制参数本轮没有驾驶用途，不搬入。

## 验收与证据边界

1. 正式入口真实生命周期中，门打开逐渐显露玛丽，玩家仍可移动；没有变成 CG 或魔法生成。
2. 玩家从两个侧面接近、忽略细节、先触碰、往返或离开再返回均可；观察动作不是操作前置。触碰失败有可见反馈，不因隐藏 Quest bool 解锁。
3. 灰盒母亲能走、转身、停顿、用一次小动作与玛丽同场；自动姿态测试只证明动作执行，是否像认识多年的车由非实现者开放复述判断。
4. 一件细节通过位置/动作/构图自然出现，不用发光热点清单或长文本解释。局部动作可读性不冒称完整情感。
5. 镜头只用当前需要的局部构图，移动方向连贯，无玩家被墙、镜头或输入困住；不能为过数字指标加强提示。
6. 实际 L1/L2 局部逻辑/输入、L3 范围与错误探针、L4 正式 SceneTree 与键盘事件、渲染采样、独立代码审查和 L5 非实现者人工记录分别保存。ERROR 即失败；有效 RED 不能是解析/导入错误。
