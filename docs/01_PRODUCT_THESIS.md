# 产品主张 / P1

版本：0.1；依据：[Owner Decisions](00_OWNER_DECISIONS.md) OD-003..006、OD-010、OD-019。
状态：方向已确认，体验尚未验证。

## 为什么存在

《锈路长歌》希望让玩家在一个持续衰败的世界中，带着无法带走的家的记忆，与一辆旧机器继续前进。自由旅行和具体人物的情绪必须共存：旅程属于玩家，几件重要的东西逐渐变得无法忘记。

旧设计被认真执行、拥有成熟服务和大量测试，不证明它值得继续。本次开发不能再从“RPG 应该有什么”出发。

## 两项承诺

**这是我的旅程。** 玩家能产生自己的目标，选择目的地、追逐或放弃目标、承担或避免风险，决定怎样生活和继续旅行。《重装机兵》提供这项设计精神，不提供可直接照搬的系统清单。

**这件东西我以后不会忘记。** 故事表达克制，少量物件、人物、文字和声音可反复出现并获得新意义。《去月球》提供这项设计精神，不意味着把整个游戏做成不可操作演出。

序章的离家有明确情境，不等于现在已经验证自由公路玩法。未来如何从家庭故事走向玩家自发旅程仍是待验证问题。

## 当前体验链

主角约一年没有进入地下车库。家庭已经无法继续等待。玩家走进去，认出父亲留下的玛丽，从生活痕迹确认她属于这个家；检查发现不可能的变化；与母亲重新启动她，自己开出去。

玩家自然想知道她是否还能走、这一年发生了什么。基础移动、观察、检查、短距驾驶由这段体验需要而产生。装备槽、赏金板、任务日志、资源经济无法以这一段证明存在价值。

## 可证伪的假设

| 假设 | 反例/失败信号 | 证据 |
|---|---|---|
| 家庭痕迹让玛丽区别于通用战车 | 玩家只说“初始载具”“强力装备”，无法指出生活细节 | 无引导复述、观察录像 |
| 自己靠近与检查比讲解更能形成关系 | 玩家靠弹窗知道一切，操作只成了点下一句 | 实际输入与视线/行动记录 |
| 异常形成私人尺度疑问 | 玩家立刻断言古代神器，或完全没有注意 | 试玩后的开放提问 |
| 启动/驶出形成继续走下去的愿望 | 玩家只等待片段结束，无继续意愿 | 自述与行为，记录反例 |

这张表是 POC 的验证提案，不是已取得的玩家结论。不得以评分总和替代具体证据。

## 设计准入

每次新需求先问“玩家此刻到底在经历什么？”然后说明人物处境、欲望、必要行为和最少机制。增加内容量、追求完整、系统深度、复用方便和架构优雅都不是开工理由。
