## C0 的五个问题

1. 自由移动时，构图能否稳定看清玛丽、人物与车库出口？
2. 胶囊人走近粗车体时，尺度是否可信？
3. 玩家能否自然走到车体至少两个侧面，持续遮挡与输入方向是否妨碍环绕？
4. 只测一次从车外进入驾驶，切换是否自然且没有输入、镜头或空间错误？
5. 玛丽能否低速驶出狭窄车库；起步、转向、停车的最少迟钝是否增加重量感而仍可操控？

具体工单：[RB-C0-001](tasks/RB-C0-001.md)。一轮最小实验、一次有限空间调整后提交可审证据或失败结论；不因失败扩建框架。工量如实记录，未确认数字不能写成 Owner 预算。

C0 已知：重量感不等于滑行惯性；缓起步、有限转向、松键即停与撞墙不滑移是候选经验，不是产品车辆模型。

## C1 的核心人物验证

无面捕/脸部特写，仅靠身体、站位、停顿、声音、有限镜头，观察母亲的意图、熟悉感和情绪是否可读；记录误解。母亲站在车旁的戏必须成立，不能只验证战车体积。动作候选不直接成为正式资产。

七段车库过程是期望经历，不是必须逐步解锁的状态机。合理提前发动/看别处允许，世界反应接住行动。真实物理原因才能限制；看过损伤不改变发动机，禁止 damage_seen 解锁。第一发动失败不是必演；任何失败要有真实原因和场内可理解反馈。
