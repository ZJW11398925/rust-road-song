# 玛丽第一次出现：视觉与叙事 POC / P3

版本：0.2；状态：验证方案提案，等待 RB-DISC-001 技术评估与 Owner 审查。首要里程碑不是完成架构或整个序章。

## 唯一问题

哪种视觉空间与叙事语言最能让玩家相信：玛丽是一辆真实陪伴家庭很多年、未来还会陪自己走很远的车？

## 最小内容

一个简化的家、一个地下车库、主角、母亲、玛丽、车库门、可检查损伤、极少台词、基础移动与镜头、启动和驶出。不给物品管理、车况数值经济、任务系统或战斗找借口。

| 环节 | 玩家行动 | 必须观察到的结果 |
|---|---|---|
| 进入 | 从简化家进入地下车库 | 空间连续、控制可用；没有进入即退出的循环 |
| 首见 | 玩家看见玛丽，可短暂取景 | 车体可见，先感到旧；家庭痕迹有读取机会 |
| 接近检查 | 自己靠近，选择观察损伤/痕迹 | 正确目标与反馈；不是点属性列表 |
| 发现异常 | 对照先前损伤信息与当前变化 | 形成“不可能的变化”的疑问，不揭答案 |
| 发动 | 与母亲做最少启动动作 | 输入、机械反应、声音/动作形成因果；她参与 |
| 驶出 | 玩家控制玛丽经过车库门开出去 | 碰撞/空间/镜头稳定，结束点明确，可重新试玩 |

## 对等实验协议（待审）

A/B/C 使用相同剧情、信息量、家庭痕迹、损伤对照、可走路径与结束点；允许镜头和表现手法不同，记录原因。先选共同的低成本内容脚本，再分别表现，不共享完整游戏框架。
提案：每条路线设相同制作预算、同硬件/显示条件、相近完成度；试玩顺序轮换，避免顺序偏差。人数、时长、预算和具体门槛由方案明确提交 Owner，不在本文件编造已批准数字。
不先告诉试玩者“这是家的记忆”“这是生长金属”，保留玩家自己的解释。静态图仅辅助构图与资产审核，胜出必须以可玩全过程为依据。

## Visual POC 必须交付的证据（不是 Discovery 交付要求）

- 三个可运行版本、版本/提交、启动方式、输入说明、完整进入到驶出的录像；标明占位与不支持内容。
- 实际制作工时、资产列表/来源/许可、手工返工、性能环境与帧时间；无头数据不能代替 GPU 实测。
- 非实现者试玩步骤与原话，观察了哪些细节、忽略了什么、何时卡住；成功和反例均保留。
- 用开放问题收集：玛丽给你什么感觉？哪些东西让你认为她属于这个家？损伤发生了什么？驶出后想做什么？
- 技术证据与情绪证据分开，最终由 Owner 裁决。三条均失败时改表现或试验设计，不能强行选分最高者。

## 指标提案

| 维度 | 观察/记录 | 不能冒充 |
|---|---|---|
| 家庭归属 | 能否指出具体痕迹，复述关系 | 文本标签“家庭战车” |
| 旧与重量 | 首感原话、接近/启动/驾驶行为 | 面数、分辨率、截图 |
| 异常可读 | 发现位置、旧损伤对照、疑问表述 | 特效已播放 |
| 操作叙事 | 台词时真实移动/观察与重新接近 | 方法调用成功 |
| 继续意愿 | 驶出后的开放回答与犹豫 | 自动测试数、单一总分 |
| 制作可持续 | 工时、返工、未来同车痕迹更新成本 | “AI 生成很快” |

## 验证顺序

方案审查 → 获得 DMCP 当前依据与实际准入 → 最小实现 → L1/L2 → L3 → L4正式入口真实输入全流程 → L5非实现者试玩 → Owner 路线决定。当前没有游戏代码，L1-L5 游戏验证均未运行。

失败路径至少覆盖：太远检查、重复交互、跳过/走开对白、提前启动、启动失败、门未开驾驶、碰撞/门槛卡住、镜头遮挡、短演出后控制恢复、失焦按键、重玩清理。用玩家可见结果验收，不靠内部状态。

## 三门细化提案（外部评审建议，待 Owner 审查）

依据 [本轮外部审查](governance/sources/2026-10-10-external-reboot-review.md)。这不批准三个可运行成品同时开工，也不提前选路线。

| 门 | 当前交付 | 进入下一门的条件 |
|---|---|---|
| Discovery | RB-DISC-001 一份短污染地图与 A/B/C 最小方案；资产、工量、风险、公平比较和待裁问题 | 上游准入修复、首单合法执行、Owner 审查具体方案；此门无程序/生产资产 |
| Greybox POC | 按获批路线/顺序使用方块、capsule、粗车体及占位材质，跑通进入→开门→首见→接近检查→异常→发动→驶出 | 真实镜头、遮挡、距离交互、控制切换、驾驶和错误反馈成立；记录工量/失败及 Owner 继续决定 |
| Visual POC | 只在成立的空间/交互上加入统一审核的家庭痕迹、材质、动作、声音，按上述同片段协议做 A/B/C 比较 | 非实现者试玩与完整过程证据，由 Owner 裁决情绪表达和制作可持续性；可以全部否决 |

Greybox 不以美术精细度或家庭情绪打分，也不跳过 AGENTS 要求的相关 L1–L5：非实现者可先验证操控/空间，正式“玛丽是否值得记住”的情绪比较放到 Visual。每门独立范围、验收和当前 DMCP 依据；前门通过不自动批准后门。AI/Blender/shader 等只在具体资产方案获审后评估，不先采用插件/服务。

## 阶段门

RB-DISC-001 先输出污染审计与三方案最小技术比较，不编码。Owner 审查后再定义有边界的 POC 实施任务。POC 结论不能证明公路自由、完整战斗、全序章或正式资产量产已经成立。
