## 要解决的体验问题

首见POC的进入、接近、异常、母亲参与启动、短距驶出已经技术贯通。下一步让玩家在正常游玩距离看懂两件事：玛丽是一辆长期使用、被家人修补的旧机器；母亲正在具体做事，动作与车的反应有关。先回答表现能否支持当前行为，再决定更大的制作投入。

依据：[产品主张](../01_PRODUCT_THESIS.md)的旅程与旧物意义、[故事正文](../02_STORY_BIBLE.md)的家庭车辆、[序章设计](../03_PROLOGUE_DESIGN.md)的首见/共同启动、[叙事语言](../04_NARRATIVE_LANGUAGE.md)的行动优先、[视觉方向](../05_VISUAL_DIRECTION.md)与[POC计划](../06_VISUAL_POC_PLAN.md)的可玩验证。新的[继续原话](../governance/sources/2026-10-13-owner-continue.md)允许准备提案；Visual采用仍待Owner。

已决：产品重置、Godot/Windows/键盘POC、C先试、当前首见操作链。未决：路线最终选择、人物年龄/正式造型、玛丽车型/行走结构、异常真相、离家决定及自由旅程是否承接家庭故事。现有机械结构与动作均是可撤回候选，不成为故事事实。

## 三个可行推进方向

| 方向 | 明确假设与交付 | 成本与局限 |
| --- | --- | --- |
| C：一轮完整首见表现试样，推荐 | 同一可玩链条中，车辆大形/修补材质、人物剪影/接触动作、照明共同使当前行为可读 | 可沿当前原型验证；仍需重新核相机、遮挡、碰撞。不能据此宣布C胜出 |
| A：最小像素2D可玩对照 | 更受控的构图与抽象是否让人物/旧物关系更清楚 | 需要另建平面场景和操作映射；当前没有证据说明A较差。采用时另写其需求和准入 |
| C：只修人物动作与接触姿态 | 母亲具体参与是否主要受灰盒人体与姿态限制 | 较小一轮，能解决接触表达；无法回答旧车材质和整体表现成本 |

B仍缺独立体验假设，暂不制作。公平审查不要求同时制作三条路线；不能把C可玩样本与A未制作的想象比较，也不能以静态漂亮图裁决路线。

## 推荐轮的五项需求

### PLAYER NEED

玩家自由接近、触碰、启动时，需要从车身与人物动作判断眼前是什么、母亲正在干什么。只有彩色盒子和文字反馈会让既有动作因果、旧物身份主要依赖说明；缺少这轮表现验证，无法判断当前空间与操作是否支持设计正文的首见体验。不是验证完整家庭情感。

### NARRATIVE / GAMEPLAY CONTEXT

家正逐渐难以维持，玩家来到车库；玛丽是父亲长期修补的家庭车辆，母亲在车旁参与工作。玩家可按自己的路线接近，观察或不观察局部异常，亲手启动，随后两人短距驶出。沿RD-012已采用的灰盒行为，不新增信件、父亲命运或母亲离家决定。早到失败候选须有真实机械原因；晚到可首次成功，观察损伤不能解锁发动。

### MINIMUM IMPLEMENTATION

一个独立工程，一辆玛丽、两个简化人物、现有车库与短空地；沿现有行为链。一轮初样加一次集中修正，以实际制作记录判断是否值得继续，不用资产数量或漂亮程度验收。

- 玛丽：调整大形和材质层次，使金属、修补接缝、磨损可区分；只表现既有局部旧损伤/新组织，不添收藏物、武器或车辆能力。低饱和旧漆、钢与锈色是试样候选。履带灰盒不锁定正式车型。
- 人物：保持简化人体，以剪影、朝向、手臂/身体接触关系表达母亲压住接点、收手、上车及玩家操作。服装与配色只用于区分，暂不确定姓名、年龄、时代细节或正式角色设计。
- 操作位置：使当前座位有清楚可见的支撑和接近空间，避免人物浮在平顶上的印象；局部试样结构不确立正式驾驶舱。不得顺势扩展整车内部或登车系统。
- 车库：保留高墙及自动透明，检查门口、两侧接近、启动和驶出时的遮挡；不以降墙替代。仅调整当前照明与必要材质。
- 提示：保留必要输入和失败原因，缩小遮挡腿部的大片提示区；不增加解释剧情的文字或UI框架。
- 碰撞：外形改变必须核对实体范围，处理当前踏步突出底盘约0.17m的问题；不得只修画面并沿用失配碰撞。

仅使用Godot内建网格/材质手工制作本轮候选，不接入新插件、付费资产、SDK、外部生成服务或音轨。每项保存比例、造型、材质、配色、年代、磨损、异常、技术规格及工具/来源/日期/使用权/人工修改记录，不能把候选标为正式资产准入。

### WHY NOT LESS

只换颜色不能改善手与接点的关系、座位支撑或提示遮腿；补一段解释不能验证自由接近时的可读性；静态图不能检查透明高墙恢复、人物动作和驶出。只做动作是合理替代方向，但它留下“旧而长期使用的机器是否可见”未验证。本轮因此限制在同一小舞台的形体、材质、动作和必要照明，不追加记忆物件或剧情。
