需求五项：

1. 玩家需要：正常距离看清生活空间和两个人，避免普通几何体/噪点代替视觉语言。
2. 剧情语境：母亲与主角同场的地下车库边缘；静止观察，不新增剧情、动作机制或道具故事。
3. 最小实现：一张环境+人物参考样张；当前V0已有材质/人物比例/光色试改，保留碰撞、输入、镜头、动作及玛丽占位。
4. 为什么不能更少：仅用“厚涂”文字或给失败灰盒加滤镜无法说明材料、人物与光色是否统一。
5. Legacy依赖：NONE。运行材质沿用已有Godot官方MIT资源；不自研渲染系统。
