## 当前理解与来源

玛丽先是家中多年使用的旧车；父亲走前有明确损伤，一年后出现不可能变化，留下私人问题“玛丽这一年发生了什么”，不解释异常来源（[故事基础](../02_STORY_BIBLE.md)）。车库检查发生在玩家亲自行走、观察与行动中（[序章](../03_PROLOGUE_DESIGN.md)、[叙事语言](../04_NARRATIVE_LANGUAGE.md)）。C1-B最终候选是旧损伤→异常→尝试启动→母亲参与→驶出，但应另裁范围，不能把观看顺序写成世界限制（[分阶段方案](../06_VISUAL_POC_PLAN.md)、[RD-009原始决定](../governance/sources/2026-10-11-owner-c0-close-c1a.md)）。

C1-A已有一名非实现者读成“抚摸一个老朋友”，也有区域切镜、右侧视角、强制右侧与入口遮挡反例。当前高墙自动透明候选技术验证通过，Owner暂时保留；母亲动作强调、完整视野/过渡及镜头舒适仍有未知。下一轮不能宣布这些已全部解决，若同类反例重现，应记为仍未解决。

## PLAYER NEED

玩家已能主动靠近旧车，下一次观察应改变他对眼前物件的理解，而非看到一块装饰后被告知“发现异常”。缺少这一小轮，直接接启动/驾驶会把谜团是否成立和操作是否顺畅混在一起，无法判断玩家为何继续关注玛丽。

## NARRATIVE / GAMEPLAY CONTEXT

人物处境：主角约一年未进地下车库，此刻与母亲同场，眼前仍是熟悉的旧车；不据此推断母亲也一年没有进过车库。玩家欲望：靠近、看看旧伤、触碰或绕开。行为：自主观察一个旧损伤部位，与母亲同场，不接受解说式任务清单。信息变化：过去留下的损伤与当前形态不相符，疑问仍属于这辆车而非世界观讲解。

这是序章节拍8–9的有限研究候选，不是完整家庭关系、异常本质或3D路线胜出的验证。

## MINIMUM IMPLEMENTATION

以下均为待Owner批准的实验候选，未成为故事设定：

1. 另建独立灰盒舞台，保留可开门、自由绕车、双方最低人形与必要局部构图。C0不改，C1-A工程不扩成新阶段，不沿Legacy开发。
2. 只选一处车壳裂口：旧破损边缘与跨过裂口的不规则新组织并置。灰盒形体/材质对比先回答“与普通补片有何不同”；暗红只作候选，不生成正式资产、特效或AI图像，不确认生物金属/自愈真相。先选车壳前部侧板作为可近观位置，可自由走任一侧，不能因细节位于一侧就把其他行动判为失败。正式部位/车体型号仍未定。
3. 母亲在这个部位停一下，手沿旧裂口边缘移动后收回。最多一句候选短文本：“这裂口，他走之前还没补上。”其功能仅提供过去状态；不补造谁来过车库、不解释变化来源、不宣称父亲死亡。普通说话期间保持移动、观察和就近触碰。
4. 不用发光标记、热点清单、检查计数、属性页、强制特写或字幕“异常已发现”。玩家可先触碰、忽略部位、走开/返回、打断观察或离开；第一次触碰不强制结束新片段，也不要求听完母亲才能行动。原C1-A结束方式仅适用于原实验。
5. 本小轮没有发动、驾驶或机械修理，故不会建立damage_seen/看过对白等解锁状态。之后真正申请启动时仍须独立说明机械因果，不能继承观察结果作为发动条件。不能靠本小轮省略这些路径就声称“提前发动已验证”。

## WHY NOT LESS

仅换一块颜色只会证明玩家看见材质；静态截图不能检验自由移动时裂口是否可读；只有一句“它变了”又会把理解交给讲解。一个保留旧边缘的部位、最低过去信息和一次母亲反应，足以检验自然信息变化，不需要完整启动/驾驶、第二处损伤或异常答案。

短文本只是候选最少上下文，若玩家只靠字幕复述而无法指出形态差异，不能记为视觉表达成功；若玩家读成普通维修，保留为反例，先改本部位，不增加解释长文。
