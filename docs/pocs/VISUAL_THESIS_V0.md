| 问题 | 本轮候选语法 | 观察与失败条件 |
| --- | --- | --- |
| 形 | 玛丽低而厚，大平面与少量不齐的修补块；人轻微概括，关节关系清楚。现有外包络不扩大 | 正常距离辨认车的质量和人的姿态；若只像规则积木或细节破坏主体，记录失败 |
| 面 | 概括式金属，旧漆偏哑光、裸钢稍亮；少量接缝表达修补，避免照片锈纹和满屏噪点 | 旧漆/修补/异常不是同一颜色斑；不命名异常真相 |
| 色 | 冷灰蓝背景，玛丽旧灰绿，有限锈土暖色；母亲低饱和暖色、玩家冷色用于辨认 | 色块支持主体，不发光、不作神器；服装不锁人物身份 |
| 光 | 软环境光与一束克制方向光，保留体块阴影；不做英雄逆光、出发音乐或标题 | 暗部不吞手和车侧；自动透明后不出现明显层叠遮挡 |
| 密度 | 远看轮廓、中距离看材料大区与少量维修线，近处保留一个局部异常 | 仅正常摄影视距评是否可读；不以多放物件改善评分 |
