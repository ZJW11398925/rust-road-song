# 视觉主张 V0：旧机器与日常协作

当前依据：[Owner采用《极乐迪斯科》外观参照并纠正概念图期待](../governance/sources/2026-10-13-owner-disco-adoption.md)。具体采用标准见[实机参照](VISUAL_STYLE_REFERENCES.md)；下面是旧SERVICE参数候选，不能当成最新风格已经落实。实际可达到的表现程度须由可复用资产的Godot小样决定，概念图不作生产/验收标准；未验证的几何人物与灯光试改已撤回。玛丽造型先服从整体标准，不自动进入正式资产/V1/V2。

SERVICE候选，供本轮真实画面检验；Owner采用实验范围，不等于采用下列参数或最终造型。

| 问题 | 本轮候选语法 | 观察与失败条件 |
| --- | --- | --- |
| 形 | 玛丽低厚斜面、圆端履带、承重轮与短炮管候选，少量不齐修补块；人轻微概括。原碰撞保持 | 正常距离辨认车的质量和人的姿态；坡面外观与箱形碰撞差异保留，不锁正式车型/武器 |
| 面 | 概括式金属，旧漆偏哑光；既有补板分为重涂漆与裸钢两种候选，暗焊缝和低对比混凝土支撑同框，避免照片锈纹和满屏噪点 | 旧漆/修补/异常不是同一颜色斑；不编造维修事件、不命名异常真相 |
| 色 | 冷灰蓝背景，玛丽旧灰绿，有限锈土暖色；母亲低饱和暖色、玩家冷色用于辨认 | 色块支持主体，不发光、不作神器；服装不锁人物身份 |
| 光 | 颜色环境光、低亮度环境反射、方向主光与局部补光，保留体块阴影；不做英雄逆光、出发音乐或标题 | 暗部不吞手和车侧；自动透明后不出现明显层叠遮挡；指定帧改善不等于全路线解决 |
| 密度 | 远看轮廓、中距离看材料大区与少量维修线，近处保留一个局部异常 | 仅正常摄影视距评是否可读；不以多放物件改善评分 |

母亲与车只是同场比例和行为背景，接点/座位/按住F/履带保持功能占位。不制作精细电路、驾驶舱、家居故事道具、人物脸部或正式动画。车型、轮履结构、旧伤位置仍可撤回。驶出只停在短空地，未决定离家。

本轮最多说明该候选是否值得继续；Godot几何不能裁决C艺术上限。V1若另采用，再明确单一玛丽资产的规格、工具/许可、可编辑性和真实修整成本；V2另验证人物关系。A保留、B尚缺独立假设。
