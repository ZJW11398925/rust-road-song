# 视觉方向 / P3

版本：0.3；依据 OD-010、修订后的 OD-015..017、RD-007及RD-012的有界POC接续。**UNDECIDED：没有获胜路线。**

## 共同艺术问题

长期目标是让玛丽像真实陪伴家庭多年、未来继续同行的车。首见是旧与长期使用，不是神器。Garage POC 先证明空间、体积、镜头、人物/车同场协调、自然检查、异常可读及启动/驾驶；不能单独证明完整情感关系。

## 三条候选与实施资格

| 方案 | 独立体验假设 | 当前安排 | 最大风险 |

| C Stylized 3D | 战车体积、道路空间、长期痕迹、材质变化与人物同场可能受益于 3D | C0已阶段接受；C1-A未知保留；RD-011异常小轮已阶段接受，RD-012另取准入接续最低启动/母亲参与/短驶出；Visual仍另审 | 镜头与检查冲突、控制切换、人物戏和制作成本 |

公平审查不要求三条全部开发。进入可玩实验的路线对齐要回答的问题、必要上下文与约束，允许各自选择动作、构图和有意义的细节；不要求相同物件数量或硬走同一顺序。记录投入、占位和完成度，不能用灰盒对精修判优。

## C 的限制

固定/半固定镜头；不默认写实人物、真人比例、面捕、360°摄影、大开放世界或 AAA 精度。C0 成立只说明值得再试 C1。C1 必须检验人类戏：不用脸部特写，身体/站位/停顿/声音/有限镜头能否传达意图；战车好看不能抵消人物失效。

## 资产审核与 AI

比例、造型、材质、配色、年代、磨损来源、腐败逻辑、技术规格统一审核。AI 是生产工具；当前 C1-A 仍不生成正式美术。后续具体资产需记录版本/模型、输入、日期、许可/使用权、人工修改、规格和回退。未经 Owner 采用的服务、插件、付费资产不得接入。
