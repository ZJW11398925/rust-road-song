# 视觉方向 / P3

版本：0.1；依据 OD-010、OD-015..017；**UNDECIDED：没有获胜路线。**

## 共同艺术问题

玩家必须相信玛丽真实陪伴这个家庭很多年，未来还会陪自己走很远。首见是旧、长期使用和反复自修的机器，不是传奇神器。
家庭磨损与世界异常衰败要能区分；暗红组织如采用，既不明确善恶也不明显是升级特效。灯光、镜头、尺度、材质和声音共同建立关系，不能只追截图漂亮。

## 三条候选

| 方案 | 当前要验证的能力 | 关键风险 | 对等条件 |
|---|---|---|---|
| A Pixel 2D | 少量像素与构图能否读出旧车、家庭细节和异常 | 细节尺度不足、车体重量与启动动作需额外表现 | 同片段、同痕迹与损伤、实际接近检查驾驶 |
| B Hybrid 2.5D | 3D 空间/战车与 2D或混合人物是否形成可信统一关系 | 透视/光照/遮挡和角色朝向不一致，管线双份成本 | 不是只把人物贴到漂亮 3D 截图 |
| C Stylized 3D | 受约束构图能否加强体积、道路空间、材质变化和长期痕迹 | 美术成本、人物动作、镜头遮挡及过度写实 | 固定/半固定游戏镜头，控制制作范围 |

优先测试受约束 3D 镜头是条件性倾向，不是 C 获胜。旧像素路线也没有保留资格加成。
不默认写实角色、真人比例、复杂面捕、360°自由摄影、大开放世界或 AAA 精度。

## 资产审核共同维度

比例、轮廓造型、材质响应、配色、世界年代感、磨损来源、腐败逻辑、技术规格。每条路线先有一个玛丽/车库标杆再做同类内容；不把不匹配的旧资产硬塞进来。
测试不因精度不等而故意偏袒方案；产出记录投入时间、占位与完成度，禁止把一条灰盒和另一条精修版本直接判胜负。

## AI 边界

概念设计/多视图、基础网格、镜头动作预演、一致性审核可以评估。未指定工具、未批准服务、未生成正式资产。
正式接入记录来源、版本/模型、提示或输入、日期、许可/使用权、人工修改、规格审核、失败与回退。生成成本与返工必须计入比较，不能把“看起来不错”当可用于游戏。
